API Documentation
POST Send Notification Message
<%= host %>/send-message
Key Type Required Description
api_key String Yes Pass in Header (x-api-key) or Body
sessionId String Yes The unique Session ID of your WA instance
phone String Yes Phone with country code (e.g. 923...)
msg String Yes Message Text content
delay Integer No Custom delay in ms (Default: 5000) 
curl -X POST <%= host %>/send-message
-H "x-api-key: <%= apiKey %>"
-H "Content-Type: application/json"
-d '{
  "sessionId": "923001234567", "number": "923001234567",
  "msg": "Hello! Your account balance is updated.", "delay": 3000
}'
Note: bulk API hits are processed via Global Queue to prevent WhatsApp bans.
